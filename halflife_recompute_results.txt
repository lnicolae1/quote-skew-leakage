HL* = 60 * ln(0.5) / ln(mean_phi).  mean(HL) is the already-committed average of per-seed half-lives.
HL* is the one to cite. mean(HL) averages a quantity with a pole at phi=1 and is unstable.
Where both use the SAME seeds, convexity gives mean(HL) >= HL* and the ratio is a dispersion
Factor (never a standard error). Where mean(HL) dropped non-stationary seeds it is computed on
a different, downward-biased sample and the ratio can fall BELOW 1; flagged inline. No
Interval is available on HL*; see the header for why.

D. What to cite, and what Step 7 should use
============================================================================================================================
  A '!' on a dispersion ratio marks a row where mean(HL) dropped non-stationary seeds, so the
  two columns are not on the same sample and mean(HL) is biased DOWN there. Combined with the
  pole inflating it elsewhere, mean(HL) errs in both directions depending on the row; which
  is why it is abandoned rather than corrected.

  Cite HL*. The committed mean(HL) columns are superseded by this file and should not be
  quoted again; they are printed above only so the size of the correction is visible.
  The holding period for step 7 should be set off HL*, and it should be set off a range
  rather than a single row; no interval is available on any of these point estimates, so
  treating any one of them as precise would be a second version of the same mistake.
