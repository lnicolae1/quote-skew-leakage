C. The addition share; what replaces the divide-by-2
====================================================================================================
  share = (CREATED + UP) / (CREATED + UP + DOWN + REMOVED)
  SAME and ZERO_ABS are excluded from the denominator (they are not
  changes to apportion); both counts are printed above so the
  denominator can be rebuilt by hand.

  All levels      (1246383 + 14580) / 2523233 = 1260963 / 2523233 = 0.499741
  within 50bp    (1218162 + 13735) / 2458227 = 1231897 / 2458227 = 0.501132

  The assumed value was 0.500000 (the divide-by-2).
  measured all   / assumed = 0.499741 / 0.5 = 0.9995x
  measured near  / assumed = 0.501132 / 0.5 = 1.0023x

  The near figure is the one to quote: the 1000-level snapshot cap
  cannot bind inside 50bp, so limitation (4); the only one that
  inflates additions; does not apply there. Limitations (1) and (3)
  still deflate it, so near is a lower bound on the addition share.

D. The implied submission ceiling
====================================================================================================
  Two routes, and they answer different questions. Both are printed
  because multiplying a share by the wrong rate is exactly the error
  limitation (5) warns about.

  Route 1; directly measured, and this is the defensible one.
  Count the addition entries and divide by the wall span. No share,
  no assumed rate, nothing multiplied.
      All   1260963 additions / 194813.671 s = 6.4727 additions/sec
      near  1231897 additions / 194813.671 s = 6.3235 additions/sec

  Route 2; share x update-ID rate. Assumes additions and
  non-additions are netted at the SAME rate inside the 100ms window,
  which is NOT established. Reported for comparison only.
      All   0.499741 x 14.3500 IDs/s = 7.1713 /sec
      near  0.501132 x 14.3500 IDs/s = 7.1913 /sec

  For comparison, the numbers this replaces:
      assumed half-rate ceiling (lam_ceiling_arithmetic.py)  10.4491 /s
      the unsourced 3.09 constant                             3.0900 /s
      committed lam                                           1.8040 /s

  What this does and does not settle. Route 1 near is a measured
  lower bound on the real book's order-addition rate. A lower bound
  on the ceiling can only raise the ceiling relative to a bound that
  sits below it; it cannot lower one. Whether that flips the
  life=60 verdict is arithmetic on this number and is NOT done here:
  this script measures, it does not re-verdict. Nothing is retuned,
  swept or simulated, and the clipping rule is untouched.
