  Level-alone is 1.000000 by construction, not by measurement: skew is -q*C, so the level
  feature is an invertible function of q and nothing can beat it. 'Which carries the
  predictive weight' is therefore answered before the run. The informative column is
  velocity-alone: it is what stays readable if a defense freezes the level.

  raw velocity  = skew[t] - skew[t-L]. Contaminated: skew = -q*C and C decays with the
                  horizon, so the difference mixes inventory change with clock decay --
                  the same artifact that depressed raw-skew R2 in step 4.
  norm velocity = skewnorm[t] - skewnorm[t-L], proportional to the inventory change alone.
